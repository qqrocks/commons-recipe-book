## How to add a recipe

1. Fork this repo (or cut a branch).
2. Drop your recipe in as a Markdown file inside your folder, named after the dish — e.g. `/akash/palak-paneer.md`.
3. Open a pull request. That is it.

One recipe per file: ingredients, steps, and a photo if you have one.
